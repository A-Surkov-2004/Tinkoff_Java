# Многопоточная генерация "Фрактального пламени"

Данный проект реализует генерацию изображений "Фрактального пламени"

Afin.java - запись, содержащая афинное выражение

AfinGen.java - класс, создающий афинные выражения

Drawer.java - класс, отвечающий за отображение сгенерированного отображения

Image.jpg - холст, поверх которого создается изображение

Modifiers.java - класс, отвечающий за применение нелинейных функций

Pixel.java - запись, содержащая информацию о пикселе

Render.java - класс, отвечающий за генерацию изображения


Запуск кода осуществляется через тесты, расположенные по адресу

https://github.com/A-Surkov-2004/Tinkoff_Java/blob/project4/src/test/java/edu/project4/RenderTest.java
